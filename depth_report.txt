 1/4  USB 设备枚举
====================================================================
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 001 Device 002: ID 2109:3431 VIA Labs, Inc. Hub
Bus 001 Device 003: ID 1bcf:2d4f Sunplus Innovation Technology Inc. DECXIN Camera
Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub

看什么：上面每一行是一个 USB 设备。
  - 出现新的一行（尤其带 Camera / Webcam / 厂商名），说明 USB 层认到了。
  - 完全没有新增行，就是硬件层问题：
    换数据线、换 USB 口、确认没和 Pi 供电口搞混、看相机指示灯。

 结论怎么读
====================================================================
  第 3 层有 'Z16 ' / 'Y16 '
      -> 相机确实有 UVC 深度流。把那个节点名和 fourcc 填进
         config.py 的 depth.uvc_device / depth.uvc_fourcc 即可。
